If a capture shows an unfamiliar field, search the glossary for the protocol and then open its page. If the glossary and the RFC disagree, the RFC wins. If the glossary and a vendor document disagree, check which version and extension the vendor implements.

A definition is a summary

“Reliable” in TCP means acknowledged and ordered, not guaranteed. “Encrypted” in TLS refers to the record layer, not the metadata. One-line definitions should be treated as pointers rather than proofs.
