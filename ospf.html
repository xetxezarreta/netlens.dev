OSPFv2 // Hello, LSAs & areas

OSPF is a link-state routing protocol that runs directly over IP. Every router floods Link State Advertisements, builds the same link-state database and runs Dijkstra's algorithm. This page covers the 24-byte header, the five packet types, the LSA header and the Router and Network LSA bodies observed in a capture.

01Header layout

24 bytes · every packet type

All OSPFv2 packets share the same header. Router ID and Area ID are 32-bit values written in dotted-quad form; Packet Length covers the header, body and any LSAs. The Checksum is an Internet checksum over the packet with the authentication field excluded.

Authentication is part of the header

AuType 0 is null, 1 is an eight-byte cleartext password and 2 is a cryptographic digest. The checksum calculation zeroes the eight-byte authentication field, so a capture with authentication type 2 still has a readable checksum.

Options are a bit field, not a list

E (0x02) is external routing, MC (0x04) multicast, NP (0x08) NSSA, EA (0x10) external attributes, DC (0x20) demand circuits, O (0x40) opaque LSAs and DN (0x80) down-bit handling. The same octet appears in Hello, DD and every LSA header.

03Link State Advertisements

20-byte header + body

Every LSA starts with a 20-byte header. The LS Type and Link State ID identify the object, and Advertising Router identifies the origin. LS Sequence Number is a signed 32-bit value that starts at 0x80000001; a larger value is newer. LS Age is capped at 3600 seconds.

LS checksum is not the packet checksum

The 16-bit value in an LSA header is a Fletcher-like checksum over that LSA only. The packet checksum in the OSPF header covers the whole packet. Do not compare them or use one to validate the other.

04Encoder

Hello or one-LSA Update

Build a structurally valid OSPFv2 packet and compute the header checksum. Hello packets take neighbour router IDs. Link State Update takes one LSA header and an opaque body so that the framing can be inspected without constructing a complete routing table.

Routing is state, not merely framing

A well-formed Hello does not create an adjacency. Neighbours must agree on area, network mask, hello/dead timers, authentication and MTU; the DR election and database exchange follow.

06Wire notes

what breaks an adjacency
  • It is not TCP or UDP. OSPF is IP protocol 89. A display filter for tcp.port == 89 will never match OSPF.
  • Hello timers must match. The dead interval is normally four times the hello interval; a mismatch prevents the adjacency from forming.
  • Area 0 is the backbone. All other areas must connect to it directly or through a virtual link. Area IDs are 32-bit values, displayed like IPv4 addresses.
  • DR/BDR election is not preemption. A new router with a higher priority does not displace the existing DR until the DR fails.
  • LS age is not an operator-set timer. It increments in the database and is capped at 3600 seconds; MaxAge flooding removes an LSA.
  • OSPFv3 is a different format. OSPFv3 runs over IPv6 next header 89, has no in-header authentication field and uses redesigned LSAs. Do not decode one as the other.
