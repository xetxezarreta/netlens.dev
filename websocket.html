WebSocket // upgrade handshake and framing

WebSocket is a full-duplex message protocol initiated by an HTTP/1.1 upgrade. Once the handshake succeeds, both endpoints exchange binary frames with an opcode, a length and an optional mask. This page covers the handshake, the frame header, fragmentation, control frames and close codes.

01Opening handshake

HTTP Upgrade · Sec-WebSocket-Key

The client sends a normal HTTP/1.1 GET with Upgrade: websocket, Connection: Upgrade and a random base64 Sec-WebSocket-Key. The server replies 101 Switching Protocols with Sec-WebSocket-Accept, the SHA-1 of the key concatenated with the WebSocket GUID, base64-encoded. After that, HTTP syntax stops.

02Frame layout

FIN · RSV · opcode · mask · length

The first byte carries FIN, three reserved bits and the opcode. The second byte has the MASK bit and a 7-bit length. Lengths 126 and 127 select a 16-bit or 64-bit extended length. A masked frame carries a four-byte masking key before the payload; the payload is XORed with the key.

Masking is not encryption

The mask key is sent in the frame and is trivially reversible. Its purpose is to stop intermediaries from interpreting WebSocket payloads as HTTP and to make cache-poisoning attacks harder. It provides no confidentiality.

06Wire notes

implementation considerations
  • HTTP/1.1 only. The RFC 6455 handshake uses HTTP/1.1. HTTP/2 and HTTP/3 have a different extended CONNECT mechanism (RFC 8441).
  • Masking direction matters. A server that receives an unmasked client frame must fail the connection; a client that receives a masked server frame must fail it.
  • Control frames cannot be fragmented. FIN must be set and the payload must be 125 bytes or fewer.
  • Text must be UTF-8. Fragmented text is validated across the complete message, not per frame.
  • Close codes 1005 and 1006 are local. They must never appear in a Close frame's payload.
  • Ping and Pong are application-visible. Intermediaries do not answer on behalf of an endpoint. A proxy may drop idle connections if the endpoints do not keep them active.
