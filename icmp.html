ICMP // RFC 792

The control and error plane of IPv4. ICMP has an eight-byte common header and a type-specific body: echo requests keep latency probes simple, while unreachable and time-exceeded messages quote the packet that caused them. No ports, no pseudo-header, and no security beyond the checksum.

01Message layout

common header · 8 bytes

Every ICMPv4 message starts with Type, Code and a 16-bit Checksum. The next four bytes are the rest of header: their meaning is fixed by the type and code, not by the common header. Everything after byte eight is the message body. The checksum covers the complete ICMP message, including the body, and not the IPv4 header that carries it.

no pseudo-header, no ports

ICMPv4 is a network-layer protocol, not a transport protocol. It has no source or destination ports and its checksum does not include an IPv4 pseudo-header. ICMPv6 is different: it uses next header 58, a separate type space and a checksum that includes the IPv6 pseudo-header.

02Types & codes

information, errors and diagnostics

The 8-bit type selects the message class; the 8-bit code refines it. Echo and timestamp messages are informational, while unreachable, redirect, time-exceeded and parameter-problem messages report errors. A handful of old types are formally deprecated and should be ignored or filtered.

ICMP is unauthenticated control traffic

Any host that can reach the path can send an ICMP error. The checksum protects against accidental corruption, not forgery. Validate quoted datagrams before changing connection state, rate-limit ICMP generation, and do not blanket-drop all ICMP: path-MTU discovery and IPv6 depend on it.

03Rest-of-header formats

the same 32 bits, different meanings

The fourth 32-bit word is where most ICMP parsers go wrong. Echo uses an identifier and sequence; redirect carries a gateway address; Parameter Problem carries a pointer. The error types that quote an original datagram also use the sixth octet for an RFC 4884 Length field when an extension structure is present.

RFC 4884 reused a reserved octet

Before extensions, the sixth octet of Destination Unreachable, Time Exceeded and Parameter Problem was “unused.” RFC 4884 redefined it as the length of the original datagram in 32-bit words. A value of zero means no extension structure. When it is non-zero, the original datagram is padded to a 32-bit boundary and an extension header (version 2) follows it.

05Decoder

raw ICMP, IPv4 packet or Ethernet frame

Paste an ICMP message, an IPv4 packet with Protocol 1, or an Ethernet II frame carrying IPv4. The decoder validates both checksums, follows the type-specific rest-of-header, and parses quoted original datagrams and RFC 4884 extensions. Raw ICMP is accepted directly, which is useful when your capture tool strips the IP header.

06Wire notes

what the pcap does not tell you
ICMPv6 is not ICMPv4

ICMPv6 is IPv6 next header 58 and is defined by RFC 4443. It has a different type/code space, includes Neighbor Discovery (RFC 4861) and uses an IPv6 pseudo-header in its checksum. Do not reuse an ICMPv4 checksum routine or type table for ICMPv6. The IPv6 explorer covers the base header and next-header chain.

  • The checksum covers only ICMP. For ICMPv4, sum the eight-byte header and the entire body. There is no pseudo-header. A receiver summing the message including the checksum should get 0xFFFF.
  • Error messages quote the trigger. Destination Unreachable, Redirect, Source Quench, Time Exceeded and Parameter Problem carry the original IPv4 header and at least eight bytes of its payload. The quote may be truncated or rewritten by NAT.
  • Length is in 32-bit words. RFC 4884 reuses the sixth octet for the length of the original datagram when an extension structure is present. Zero means no extension. The quoted datagram is padded to a 4-byte boundary.
  • Type 3 code 4 is path-MTU discovery. The next-hop MTU in the rest-of-header tells the sender how small to fragment. Filtering this message can cause TCP black holes, especially with DF set.
  • TTL expiry is not an error in the transport sense. Time Exceeded is normal traceroute behavior. The quoted datagram is how the sender knows which probe expired.
  • Redirects are a security liability. A host that accepts ICMP redirects can be steered through an attacker. Most modern stacks ignore redirects by default or require strict source/interface checks.
  • No authentication. ICMP has no signature, nonce or source authentication. The checksum detects accidental corruption only. ICMP filtering, rate limiting and quoted-packet validation are operational controls, not protocol guarantees.
  • Deprecated does not mean absent. RFC 6633 deprecates Source Quench; RFC 6918 deprecates types 6, 15, 16, 17, 18 and 30–39. Old devices and lab traffic still emit them.
