Subnet & CIDR calculator // IPv4 + IPv6

Enter an address or prefix to obtain the network, mask, wildcard, address range, usable host count, binary representation and address type. The prefix can then be divided into equal subnets or used to plan a VLSM allocation from host requirements.

The planner allocates the smallest standard block that fits each requirement, largest first, aligned to its size. It leaves free space but does not attempt to minimise fragmentation beyond that point.

04Notes

what the numbers mean
  • /31 point-to-point links have two usable addresses. RFC 3021 allows both ends of a /31 without a network or broadcast address.
  • /32 is a single host route. It has one address and no broadcast. On a point-to-point link it is sometimes used with an explicit peer.
  • IPv6 has no broadcast. The all-zeros subnet-router anycast address is reserved, and the all-ones interface identifier is not a broadcast address.
  • A mask must be contiguous. This calculator rejects non-contiguous IPv4 masks rather than inferring the intended bits.
  • Private ranges are conventions, not guarantees. RFC 1918 space is not routed on the public Internet, but nothing in the packet stops an operator from using it internally.

The binary view shows the address split into octets. For IPv6, the binary view groups 16-bit words.
